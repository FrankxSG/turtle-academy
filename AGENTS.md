# Turtle Academy — shared agent entrypoint

Read `docs/AI_COLLABORATION.md`, `docs/TECHNICAL_DESIGN_DECISIONS.md`, `docs/FEATURE_SCOPE.md`, `docs/PILOT_V0_1_SCOPE.md`, `docs/TECHNICAL_HANDOFF.md` and `docs/FOUNDATION_SETUP.md` before work.

**This repository is public.** Every commit, branch, PR description, Issue, comment and CI log can be read by anyone and cannot be reliably deleted. Never include learner names, school details, worksheets, handwriting, photos, progress records, account identifiers, infrastructure project details or credentials, even temporarily.

GitHub is the shared source of truth for Claude and ChatGPT. Check the current main SHA and relevant open PRs; unmerged code is not the main baseline. Use the common collaboration protocol rather than separate assistant-specific rules. Record task progress, decisions and test evidence in the repository/Issues/PRs, not only in chat.

No runtime AI, real learner fixtures, privileged frontend keys or cross-project resource reuse. Preserve private learner storage, offline records and the distinction between submission/story/mastery. Full feature scope is not the Pilot build list: `docs/PILOT_V0_1_SCOPE.md` defines the only committed delivery slice. Merging and deployment remain separately approved actions. Later explicit owner instructions supersede stale records and must be reconciled in GitHub.
